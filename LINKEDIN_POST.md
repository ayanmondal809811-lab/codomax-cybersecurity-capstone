### 🌟 What is AegisTrace?
In fast-paced Security Operations Centers (SOCs), analysts battle alert fatigue across disparate authentication, web reverse-proxy, and firewall log formats. Traditional SIEM tools often require heavy server infrastructure and raise data confidentiality concerns when sensitive telemetry is sent over external networks.

**AegisTrace** solves this with an air-gapped, zero-dependency, client-side workbench that normalizes multi-vector security logs and executes real-time heuristic threat detection entirely within the browser sandbox!

### 🔑 Key Engineering & Security Highlights:
- 📊 **Multi-Vector Telemetry Parsing:** Correlates Linux `auth.log`, web WAF/access records, and kernel `iptables` drop events.
- 🎯 **Heuristic Detection & MITRE ATT&CK Alignment:** Automated detection for SSH brute-force attacks (`T1110`), path traversal (`T1083`), SQL injection (`T1190`), command injection (`T1059.004`), and suspicious outbound C2 beaconing (`T1071.001`).
- 🛠️ **Automated Incident Response Playbooks:** Provides actionable step-by-step mitigation workflows aligned with **NIST SP 800-61 Rev. 2** guidelines.
- 📄 **Forensic Reporting Engine:** Instant export of comprehensive Markdown triage summaries, machine-readable JSON, and audit-ready CSV datasets.
- 🔒 **Zero-Trust Privacy & Anti-XSS Sanitization:** 100% in-memory processing with strict DOM escaping to neutralize hostile payloads embedded in log headers.
